# Тюбик

Клиент YouTube для Android и Android TV: без рекламы, с SponsorBlock, входом в аккаунт
и встроенными обновлениями. Одно приложение для телефона и телевизора.

Версия: **0.4.1** · [Скачать APK](apk/Tubik-0.4.1.apk) · SHA-256: `93ad06620ab5a55b19b71b2d8e5b8ab3844d8405e2503b4a88a017898f39b4c1`

## Возможности

- **Без рекламы.** Видео берётся напрямую из потоков YouTube, рекламе неоткуда взяться.
- **SponsorBlock.** Автопропуск спонсорских вставок, самопиара, заставок и прочего;
  категории выбираются в настройках, сегменты подсвечены зелёным на полосе перемотки.
- **Аккаунт.** Рекомендации «Для тебя», лента подписок и история просмотров.
- **Плеер.** Media3/ExoPlayer, качество до 4K, выбор качества и скорости, эфиры.
- **Каналы.** Шапка канала, вкладки Видео / Эфиры / Shorts.
- **Автопереход.** В конце видео отсчёт до следующего похожего ролика (можно отменить),
  ряд похожих и кнопка «Далее ⏭».
- **Android TV.** Отдельная иконка в лаунчере, боковое меню, всё работает с пульта:
  ← → перематывают на 10 секунд, ОК ставит на паузу, удержание ОК или «Меню» на карточке
  открывает канал.
- **Ссылки.** Открывает youtube.com и youtu.be, работает «Поделиться → Тюбик».
- **Обновления.** Приложение само проверяет новые версии при запуске, качает APK,
  сверяет SHA-256 и ставит обновление поверх. Вручную — в Настройки → Обновления.

## Установка

1. Скачай [APK](apk/Tubik-0.4.1.apk) на телефон или ТВ (на ТВ удобно через
   приложение вроде Downloader или с флешки).
2. Разреши установку из неизвестных источников, когда Android спросит.
3. Дальше обновления приходят прямо в приложение.

## Вход в аккаунт

**Телефон.** Настройки → «Войти через Google». Открывается обычная страница входа Google;
пароль приложение не видит, оно забирает только cookies youtube.com. Если Google не пускает
(«небезопасный браузер»), выгрузи cookies youtube.com из браузера на компьютере
(расширение вроде «Get cookies.txt LOCALLY») и вставь через «Вставить cookies».

**ТВ.** Настройки → «Войти с телефона» показывает код вида `K7QM-9XRT`. На телефоне,
где ты уже вошёл: Настройки → «Передать вход на ТВ», вводишь код, и готово. Телефон находит
ТВ в домашней сети через mDNS (`_tubik._tcp`, порт 47110). Cookies передаются
зашифрованными AES-GCM ключом из кода (PBKDF2); после 15 неверных попыток окно
закрывается. Если роутер режет mDNS, на ТВ показан адрес для ручного ввода.

Cookies хранятся в данных приложения в открытом виде, так что на чужом или рутованном
устройстве лучше не входить.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36).

```bash
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew assembleDebug        # ставится рядом как dev.tubik.app.debug, без обновлений
```

Подпись берётся из `keystore.properties` в корне (в git не попадает):

```properties
storeFile=keys/tubik.jks
storePassword=…
keyAlias=tubik
keyPassword=…
```

Без него релиз подписывается отладочным ключом и поверх опубликованной версии не встанет.

## Выпуск новой версии

1. Подними `versionCode` и `versionName` в `app/build.gradle.kts`.
2. `./gradlew assembleRelease`
3. `python3 tools/release.py "Что нового 1" "Что нового 2"` — кладёт APK в `apk/`,
   пишет `update.json` и обновляет ссылку и SHA-256 в этом README.
4. Закоммить и запушь, затем сбрось кэш CDN:
   `curl -s https://purge.jsdelivr.net/gh/L1TTLEHE11/Tubik@main/update.json`

Приложение читает `update.json` параллельно с трёх зеркал (raw.githubusercontent.com,
jsDelivr, github.com/raw) и берёт самую свежую версию.

## Как устроено

```
data/
  InnerTube.kt          — WEB-клиент YouTube: ленты, поиск, авторизация через SAPISIDHASH
  Repository.kt         — ленты с пагинацией, подборки и каналы через NewPipeExtractor
  SponsorBlock.kt       — сегменты по хеш-префиксу id (сервер не знает, что ты смотришь)
  GoogleVideoInterceptor.kt — запросы к googlevideo в стиле клиента YouTube
  PairCore.kt, Pairing.kt — передача входа телефон → ТВ (сервер, шифрование, mDNS)
  Updater.kt            — проверка, загрузка и установка обновлений
  NpDownloader.kt, Prefs.kt
player/
  DashBuilder.kt        — один DASH-манифест из всех потоков, ExoPlayer сам сводит и переключает
  PlayerActivity.kt, PlayerScreen.kt — плеер и контролы на Compose (пульт + тач)
ui/
  MainActivity.kt, Screens.kt, VideoGrid.kt, ChannelScreen.kt, UpdateUi.kt, Nav.kt,
  LoginActivity.kt, Theme.kt
tools/release.py        — публикация версии для встроенных обновлений
```

## Ограничения

- Нет фонового воспроизведения, PiP, плейлистов, подписки/отписки на каналы, лайков.
- YouTube регулярно ломает неофициальные клиенты. Если видео перестали играть, первым делом
  стоит обновить `NewPipeExtractor` в `app/build.gradle.kts`.
- Приложение не связано с Google и YouTube. В Google Play его нет и не будет.
